# 术语表（程序员友好版）

| 术语 | 白话解释 | 在平台里的作用 |
|---|---|---|
| 市值 | 股价乘总股本，市场此刻给股东权益的总报价 | 规模、估值分母、风险暴露；不是现金、资产或内在价值 |
| 自由流通市值 | 真正可被公众交易的股份对应市值 | 指数权重、流动性和容量 |
| 风险暴露 | 组合对某个共同风险来源有多敏感 | 例如小盘、行业、Beta；上涨可能受益，下跌也会一起受损 |
| Point-in-time / PIT | 只使用历史当时已经公开可用的数据 | 防止拿未来财报回测过去 |
| 经济时间 | 事实描述哪个期间 | 如 2025 年年报截止 2025-12-31 |
| `available_at` | 市场最早何时可以使用该事实 | 晚于它的决策才能读到该事实 |
| 系统时间 | 仓库自己何时知道/保存某版本 | 支持回放数据回填和修订过程 |
| 历史股票池 | 某个历史时点实际存在且符合规则的证券集合 | 防止只用今天还活着的公司造成幸存者偏差 |
| 因子 | 对每只股票按统一可重复公式计算的特征 | 例如盈利质量、估值、改善程度 |
| 因子回测 | 检验因子排序与未来收益是否系统相关 | 不是完整资金账户模拟 |
| 选股策略回测 | 将因子变成持仓、调仓和资金曲线 | 包含权重、成本和交易约束 |
| 择时 | 改变整个股票资产的总仓位，而不只是换股票 | 例如从 90% 股票降到 40% |
| 主动择时 | 预测未来市场收益/风险并主动调整仓位 | 必须与静态仓位和被动控险比较 |
| IC | 某一天因子值与未来收益的截面相关系数 | 衡量排序信息，不直接等于策略收益 |
| Rank IC | 使用排名计算的 IC | 对极端值更稳健 |
| HAC/Newey-West | 在时间序列相关和异方差下修正标准误 | 防止把重复/相关样本当独立样本 |
| Fama–MacBeth | 逐期做截面回归，再汇总系数 | 检查因子控制其他暴露后是否仍有增量 |
| 多重检验 | 同时试很多因子会“碰巧成功” | 用 FDR 等方法控制假发现 |
| Walk-forward | 只用过去训练，向前滚动测试 | 更接近真实上线过程 |
| Purged/Embargo | 删掉训练测试边界附近会共享未来标签的样本 | 防止时间重叠泄漏 |
| 样本外 | 没参与选模型和调参数的数据 | 判断是否过拟合的核心证据 |
| 基准 | 用来比较的可投资参考 | 如沪深 300、全市场等权或静态满仓 |
| Alpha | 不能被基准/常见风险暴露解释的增量收益 | 需要统计和经济两方面证据 |
| Beta | 资产对市场整体涨跌的敏感度 | 组合风险和择时拆分 |
| 换手 | 调仓时买卖权重的规模 | 决定成本和容量 |
| 滑点 | 模拟参考价与实际成交价的差 | 回测必须估计，实盘必须监控 |
| 容量 | 策略能承载多少资金而不显著推高成本 | 与成交额、参与率、冲击有关 |
| InvestmentView | 一只股票在某期限的统一投资判断 | 连接基本面、事件和组合 |
| Shadow Forecast | 同步生成并冻结，但不影响真实仓位的预测 | 为新模型积累无事后修改的样本 |
| OMS | 订单管理系统 | 管理订单意图、审批、下单、成交和状态 |
| 归因 | 解释收益/风险到底来自哪里 | 区分选股、择时、行业、成本和执行 |
| 失效条件 | 哪个可观察事实出现后原判断不再成立 | 防止只写永远无法证伪的故事 |
