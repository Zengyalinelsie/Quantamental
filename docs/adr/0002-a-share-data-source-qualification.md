# ADR-0002：A 股数据源资格与字段级许可

- 状态：Accepted
- 日期：2026-08-10
- 补充：私人本地研究的受限持久化例外由 ADR-0003 定义；本 ADR 对通用 raw bulk、外部分发、严格历史和生产用途的禁止仍有效

## 背景

P2 需要公司/证券/挂牌、历史股票池、原始日线、交易状态、行业、指数成员、公司行动和股本。SPEC-015 要求在批量回填前确定主源、备用源、权威源、字段权限、许可和保存边界。免费客户端代码的开源许可证不等于其上游数据可以批量保存、再分发或用于生产决策。

## 探针证据

2026-08-10 通过现有 `a-share-mcp` 对其 Baostock 后端做了小样本探针：

- `sh.600519` 返回 2001-08-27 上市信息和 2018-01-02 至 2018-01-05 原始日线；
- 2018-01-01 至 2018-01-07 交易日历、2018-01-05 行业和沪深 300 成员可返回；
- `sh.600175` 返回 2020-08-14 退市日期，2020-05-20 至 2020-06-30 日线包含 ST 和停牌状态；
- `sz.000043` 在 2018-01-05 返回当时名称“中航善达”，说明部分日期查询具备历史名称信息；
- 2018 年复权因子样本返回空；`bj.430047` 基本信息返回空，北交所覆盖不足；
- 工具报告最新交易日为 2026-08-10，但同日股票列表返回空，存在端点截止时间不一致；
- 历史股票列表中的名称不保证为当时名称，不能据此自动生成 PIT 身份历史；
- 这些接口没有公告 `available_at`、修订序列或系统时间，不能自动获得 `pit_verified` 资格。

PyPI 公共元数据在 2026-08-10 显示 Baostock 客户端为 BSD、AkShare 客户端为 MIT。该证据只覆盖客户端代码许可证，不覆盖 Baostock、东方财富或其他上游数据的保存、回测、展示和再分发权。

## 决策

1. P2 本地原型的第一主源为 `a-share-mcp` 的 Baostock 能力，仅用于沪深小样本、当前研究和明确测试 fixture。
2. AkShare 是字段缺失和北交所的备用候选；其客户端 MIT 不提升上游网页数据资格。正式 adapter 接入前仍要逐端点记录来源条款、频率和保存期限。
3. 上交所、深交所、北交所是证券身份、挂牌状态、交易日历、市场规则和公司行动的权威核验源；巨潮/交易所/公司披露在 P3 承担公告权威源。
4. Baostock/AkShare 观察的 trust ceiling 为 `normalized_current`。它们不能自行产生 `pit_verified`，也不能用于 `strict_historical` 或生产决策。
5. 当前没有任何免费源获批用于通用 `raw_bulk_persistence`、对外再分发或 Limited Live。ADR-0003 后续增加的 `private_local_research` 是受限本地例外，不改变生产/商业使用前的数据条款审查或采购要求。
6. P2 不进行未经限定的全市场批量回填。除小型、版本化合同 fixture 和明确 current 研究调用外，ADR-0003 只允许显式 ack、symbols、domains 和本地目标的 `normalized_current` 私人回填。
7. Fallback 生成独立来源观察和诊断，不覆盖主源记录；来源冲突必须保留。
8. 字段级决策由 `ProviderRegistry` 执行，文档矩阵见 `docs/11-p2-data-source-coverage-matrix.md`。

## 结果

优点：

- 可在不降低 PIT 和许可标准的前提下继续 P2 领域与查询能力；
- 北交所、复权因子、股本和身份历史缺口不会被“免费可用”掩盖；
- 未来更换商业数据源不改变核心 Company/Security/Listing/Universe 合同。

代价：

- P2 页面只能展示版本化小样本或真实空状态，不能声称全市场覆盖；
- 严格回测仍被阻断，直到 P3/P4 前的数据时间和许可得到验证；
- 生产供应商与商业费用仍是后续采购决策。

## 被否决方案

- 因 Baostock/AkShare 客户端开源而默认上游数据可长期保存或再分发；
- 用查询时点替代公告可用时间，把 current 返回标成 PIT；
- 为填补北交所、复权或股本缺口而自动填零或静默混源；
- 在许可和时间语义未确认前开始全市场批量回填。
