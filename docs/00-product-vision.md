# 产品目标与边界

## 1. 一句话目标

建立一个能把“当时可知的数据”转换成可验证的 A 股多头投资判断，并沿同一条代码路径完成组合、现实回测、模拟盘、未来实盘和归因学习的平台。

它首先是研究与决策基础设施，不是一个承诺收益的荐股机器人。

## 2. 平台回答什么

| 用户问题 | 平台输出 | 典型期限 |
|---|---|---|
| 哪些公司值得投资 | 行业内可比的公司质量与长期竞争力 | 1–3 年逻辑，20–120 个交易日决策更新 |
| 当前价格是否有吸引力 | 估值区间、隐含预期、预期差 | 20–250 个交易日 |
| 公司是否改善或恶化 | 财务趋势、经营指标、分析师预测修正 | 5–120 个交易日 |
| 新事件改变了什么 | 事件事实、影响路径、幅度、期限、置信度和失效条件 | 分钟到 120 个交易日 |
| 整体股票仓位应是多少 | 主动择时预测、被动风险基线、最终风险预算 | 1、5、20、60 个交易日 |
| 是否真实可执行 | 目标组合、订单意图、成交约束、成本、对账和归因 | 日内到持续运行 |

这里的“好公司”没有一个跨行业永久不变的分数。平台采用三层标准：

1. 通用底线：财务真实性、偿债能力、治理、现金流、资本回报；
2. 行业模板：银行、制造、软件、消费的关键经营指标不同；
3. 公司特例：商业模式、生命周期、会计口径和重大事件的明确调整。

最终排序仍应尽量在行业内比较，再由组合层控制行业暴露；不能用同一个 PE 或毛利率阈值粗暴比较所有 A 股。

## 3. 数据模式与部署阶段必须分轴

| 轴 | 值 | 输出可做什么 |
|---|---|---|
| 数据模式 | 当前研究：`normalized_current` 或更高 | 看今天的公司与新闻，必须显示可信等级 |
| 数据模式 | 严格历史：仅 `pit_verified` | 因子检验和严格回测 |
| 部署阶段 | Research | 探索和历史研究 |
| 部署阶段 | Shadow | 与真实时钟同时运行但不影响账户，积累前瞻样本 |
| 部署阶段 | Paper | 通过相应用途审批的冻结版本，可影响模拟账户 |
| 部署阶段 | Limited Live | 通过相应用途审批，并经人工与账户风控授权，可影响受限真实账户 |

当前数据很多，不等于可以回测。回测要求知道“在历史那个时点，市场参与者当时能看到什么”。

## 4. 统一决策对象

公司质量、估值、改善和事件不能停留在四个互不相干的页面。它们必须合成为 `InvestmentView`：

```yaml
security_id: security:CN:600519:XSHG
decision_time: 2026-08-10T15:30:00+08:00
horizon_trading_days: 60
expected_return:
  point: 0.045
  p10: -0.12
  p50: 0.04
  p90: 0.19
confidence: 0.62
components:
  quality: {status: quantified, contribution: 0.018}
  valuation_expectation_gap: {status: quantified, contribution: 0.021}
  fundamental_revision: {status: quantified, contribution: 0.012}
  event_adjustment: {status: quantified, contribution: -0.006}
invalidators:
  - 毛利率跌破行业阈值
  - 核心客户流失得到权威证据确认
evidence_ids:
  - fact:...
  - event:...
```

它不是“准确目标价”，而是一个带期限、区间、不确定性、证据和失效条件的可审计预测。

## 5. 主动择时的产品定位

主动择时要做，但不能和选股混为一个不可解释的总分：

```text
被动风险仓位基线
  + 主动 Timing Forecast（方向、收益分布、置信度）
  + 组合风险约束
  = 最终股票风险预算
```

主动模型先在 `Timing Lab` 研究，并从第一天记录 Shadow Forecast。只有在样本外统计指标和成本后经济指标同时过门后，才允许小权重影响生产仓位。

## 6. 第一版明确不做

- 不承诺自动找到“必涨股票”；
- 不让 Agent 自主下单；
- 不用今天的财报字段回填十年前回测；
- 不一开始构建完整商业级 Barra；
- 不一开始拆微服务、上 Spark 或 Kubernetes；
- 不把 DSA 的“报告方向命中评估”冒充组合回测；
- 不把当前本金、固定持仓数或股价上限写成平台常量；
- 不用复杂模型替代等权、行业中性和静态满仓等简单基线。
