# 实施路线图

> 状态说明（2026-08-10）：本文保留早期阶段切分作为历史路线概要，其 P0–P8 编号不再作为当前执行编号。现行 P0–P11 阶段、工作包、依赖和 Capability Gate 以 `docs/08-detailed-implementation-plan.md` 为真源；Spec 与 Plan 的裁决依据见 `docs/09-spec-plan-consistency-review.md`。

## 总原则

按可验证的纵向切片建设。每个阶段必须产出真实数据、可运行代码、测试、版本化 Artifact 和明确的未完成项，不能只增加页面和类名。

## P0：权威核心与来源审计（旧路线图编号）

目标：建立新仓库边界、领域语言和科学门。

完成定义：

- 两个来源仓库冻结为只读供体；
- 产品目标、来源审计、目标架构、迁移地图和黄金链路成文；
- `FactObservation` 能区分当前研究与严格 PIT；
- `InvestmentView` 有期限、区间、分项、证据和版本；
- 不同研究类型有代码化的最低验证门。

## P1：A 股 PIT 最小数据切片

先覆盖一个可核验小股票池和 2018 年以来数据，不追求一开始全市场全部字段。

必须完成：

- 公司/证券/挂牌三层身份；
- 上市、退市、ST、停牌、代码变化；
- 交易日历、原始不复权 OHLCV、复权因子、涨跌停状态；
- 历史股票池与行业分类有效区间；
- 资产负债表、利润表、现金流量表的报告期、首次公告、修订和 available time；
- 股本、自由流通股本、市值历史；
- 原始文件/响应 hash、来源、许可和覆盖报告；
- PIT 查询和未来数据泄漏测试。

退出门：任意历史交易日能重建“当时有哪些股票、当时已知哪版财务、下一日能否交易”。

## P2：三个基本面因子和行业模板

先做三类最能暴露数据问题的因子：

1. 质量：ROIC/ROE 与现金转换；
2. 估值预期差：盈利收益率或 EV/经营利润，按行业选口径；
3. 改善：收入/利润率/现金流趋势与加速度。

同时建立银行、非金融制造/消费两类最小行业模板，避免全市场一刀切。

退出门：每个因子是纯函数，有输入字段、单位、缺失政策、winsorize/neutralize 版本和人工样例核算。

## P3：正式 Factor Lab 与 InvestmentView

必须完成：

- IC/Rank IC、HAC/bootstrap CI、分层收益、单调性、衰减、换手；
- 行业/市值中性和 Fama–MacBeth；
- 多重检验与研究族登记；
- Walk-forward 和真正样本外；
- 因子 lifecycle 与失败实验登记；
- 第一版可解释 Expected Return Compiler；
- DSA 报告命中评估迁为独立 `ForecastOutcomeEvaluator`。

退出门：至少一个因子相对等权/随机/简单价值基线在样本外有可解释增量，或诚实得出“不成立”。

## P4：多头组合与现实 A 股回测

必须完成：

- Top-N 等权基线；
- 受约束得分权或优化权重；
- 次交易日成交；
- T+1 库存、整手、停牌、涨跌停、ST/退市、分红拆股；
- 佣金、印花税、滑点、参与率和冲击；
- benchmark、现金、资金曲线和归因；
- 内部引擎与 RQAlpha/LEAN 至少一个外部引擎对照。

退出门：相同信号在双引擎的差异能够逐笔解释，所有归因项闭合到组合收益。

## P5：主动 Timing Lab

目标不是只做波动率控仓，而是研究主动预测。

步骤：

1. 定义 1/5/20/60 日市场收益、下行风险和状态标签；
2. 建静态满仓、均线、波动率目标等基线；
3. 研究宏观、估值、宽度、趋势、流动性、风险偏好和事件特征；
4. 使用 walk-forward、HAC、概率校准和经济效用检验；
5. 从第一天记录不可修改的 Shadow Forecast；
6. 通过门槛后只允许受限权重影响生产仓位。

退出门：主动调整相对静态和被动风险基线在样本外、成本后有增量，且失败状态可解释。

## P6：事件、新闻 Agent 与供应链

必须完成：

- 文档原文与版本；
- 实体链接、事件聚类和重复来源合并；
- 事实/推断/观点/传闻分层；
- 供应链关系有效期；
- Event Study 与事件模型 Shadow 预测；
- Agent tool allowlist、预算、模型/prompt 版本、引用和审计；
- DSA 报告、工作台和通知能力逐步接入。

退出门：任何事件调整都能回答“新事实是什么、从何而来、何时可知、影响谁、为什么、期限多长、什么会证伪”。

## P7：风险模型、归因和学习闭环

- R0 行业/Size/Beta + 收缩协方差；
- R1 A 股风格因子风险模型；
- 预测收益、实现收益、选股、择时、行业、风格、事件、成本归因；
- 数据漂移、特征漂移、IC 衰减、成本偏差和模型校准监控；
- review、retire、rollback 状态机。

退出门：日收益和累计收益归因闭合，报警能够指向数据、模型、组合或执行中的具体层。

## P8：模拟盘、OMS 与实盘

- 订单意图、预交易风控、人工审批、幂等；
- 券商 adapter 与模拟账户；
- 持仓、现金、订单、成交对账；
- kill switch、权限、密钥、审计、备份和恢复演练；
- 小范围 shadow → paper → limited live 晋级。

退出门：连续运行与对账通过，故障恢复和 kill switch 演练完成；Agent 始终无直接交易权限。

## 横向工作流

每个阶段同时维护：

- W00 产品/投资政策配置；
- W01–W03 身份、数据、PIT 与证据；
- W04–W10 公司、估值、改善、事件、因子、InvestmentView、择时；
- W11–W13 风险、回测、OMS；
- W14 归因、监控和学习；
- W15 版本、权限、安全、许可和交付。
